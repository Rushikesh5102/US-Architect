# US Architects - Official Website

Welcome to the official repository of **US Architects**, a premier architectural studio based in Pune, specialized in creating high-end residential, commercial, and interior designs.

## 🚀 Live Preview
View the live website here: [https://rushikesh5102.github.io/US-Architect/](https://rushikesh5102.github.io/US-Architect/)

## ✨ Key Features
- **Premium Architectural Design**: A modern, high-end aesthetic reflecting our studio's philosophy.
- **Interactive 3D Elements**: Smooth animations and 3D tilt effects for an engaging user experience.
- **Seamless Galleries**: Infinite-scrolling project showcases for Interior and 3D Visualization portfolios.
- **Fully Responsive**: Optimized for all devices, from mobile phones to high-resolution desktops.
- **Custom 404 Page**: A branded error page to guide users back to the studio.
- **SEO Optimized**: Advanced metadata and JSON-LD structured data for better search engine visibility.

## 🛠️ Technology Stack
- **Core**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Libraries**:
  - [GSAP](https://greensock.com/gsap/) (Scroll animations)
  - [VanillaTilt.js](https://micku7zu.github.io/vanilla-tilt.js/) (3D tilt effects)
- **Deployment**: GitHub Pages
